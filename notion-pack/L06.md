## 互动课堂（讲→问→做→回忆）

### 1. SWE-bench 的闭环（explain）

locate→edit→test→iterate。harness 的价值不在写代码，在把反馈变成下一轮输入。

### 2. 没有 test 怎么办（probe）

SWE-bench 里隐藏测试是 reward。真实项目里缺失时，你用什么代理信号判断 patch 对不对？

### 3. 写一个 patch trace（build）

挑一个你最近的 bug，写出完整定位→修改→验证→迭代的轨迹。

### 4. 一句话带走（recall）

coding agent 的核心是“让模型有可调试的环境”，不是更长的 prompt。
