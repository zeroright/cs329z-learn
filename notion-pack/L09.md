## 互动课堂（讲→问→做→回忆）

### 1. RL 三元组映射（explain）

state = context+env 观察，action = tool call，reward = 任务成败。把 chat 的 RL 词汇平移过来。

### 2. 稀疏奖励（probe）

长轨迹只在终点 0/1，哪一步该给过程分？给多了会发生什么？

### 3. 为你的任务写 reward（build）

设计一个可执行、可规模化、难被 hack 的奖励函数。

### 4. 一句话带走（recall）

没有评测，RL 就是在优化噪声。
