## 互动课堂（讲→问→做→回忆）

### 1. memory 和 skill 分家（explain）

memory 回答「发生过什么」，skill 回答「下次怎么做」。把它们混在一个 RAG 里，是 agent 失忆的常见根因。

### 2. 设计技能库（build）

为你的一个真实 agent 场景写 3 个 skill：名称、触发条件、输入、输出、失败回退。

### 3. ASI vs 手写 skill（compare）

Agent Skill Induction 从轨迹归纳 skill，比纯手工写强在哪、险在哪？

### 4. 一句话带走（recall）

技能是可复用的过程性资产，需要被“写入”，不是只被“想起”。
